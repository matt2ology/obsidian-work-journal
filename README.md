# Work Journal

## Important Links

## Attribute and State System

- Use **properties for structure** → fixed, stable, queryable.
- Use **tags for meaning** → fluid, interpretive, cross-cutting.

### Use properties

**Examples:** `note_type`, `meeting_category`, `meeting_with`, `relationship`, etc.

- what the note _is_
- who it’s about
- what type of meeting
- metadata you’ll query

### Tag Taxonomy

- **Workflow:** `#todo`, `#doing`, `#waiting`, `#followup`, `#done`
- **Insights & Highlights:** `#decision`, `#idea`, `#learning`, `#important`, `#risk`, `#opportunity`, `#win`
- **Topics (optional):** `#strategy`, `#leadership`, `#performance`, `#architecture`, `#product`, `#process`, `#hiring`, etc.
